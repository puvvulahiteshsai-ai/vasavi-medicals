Sri Vasavi Medical Hall

Official website for Sri Vasavi Medical Hall, a pharmacy located in Habsiguda, Hyderabad. Built as a group internship project by three students.

Project Overview

Sri Vasavi Medical Hall is a full-service pharmacy established in 2000, serving the Habsiguda community for over 25 years. This website was designed and developed to help the business reach more customers, showcase their services, and make it easy for patients to find and contact the pharmacy.

The website is live and deployed at: vasavi-medicals.vercel.app

Tech Stack

React 18
Vite
React Router DOM
CSS (custom, no UI framework)
Font Awesome (icons)
Google Fonts (Manrope)
Vercel (deployment)

Features

Responsive design across mobile, tablet, and desktop
Smooth scroll animations using Intersection Observer
Client-side routing with scroll-spy active link highlighting
Branded loading screen on every page load
Offline detection with a fallback screen
Mobile navigation with full-width dropdown menu
Hero section with storefront photography
Services section with flip card interactions
Gallery with lightbox viewer
Real customer reviews sourced from Google Maps
About the Owner section with profile photo
Google Maps embed with accurate location pin
WhatsApp direct contact integration
Rapido delivery animation
Back-to-top button
Fully accessible with keyboard navigation and reduced-motion support

Getting Started

Requirements: Node.js 18 or higher

Install dependencies:
npm install

Run development server:
npm run dev

Open http://localhost:5173 in your browser.

Build for production:
npm run build

Preview production build:
npm run preview
